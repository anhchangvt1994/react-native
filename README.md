### PHẦN 1: SETUP MÔI TRƯỜNG (Cách nhanh nhất)

Thay vì cài đặt Android Studio hay Xcode ngay lập tức (rất nặng và phức tạp), chúng ta sẽ sử dụng **Expo**.

1. **Cài đặt Node.js:** Tải và cài bản LTS tại [nodejs.org](https://nodejs.org/).
2. **Cài đặt Editor:** Sử dụng **VS Code**. Cài thêm extension "ES7+ React/Redux/React-Native snippets".
3. **Cài đặt Expo Go:** Tải ứng dụng **Expo Go** trên điện thoại (App Store hoặc Play Store).
4. **Khởi tạo dự án:**
* Mở terminal, chạy lệnh: `npx create-expo-app@latest MyFirstApp`
* Di chuyển vào thư mục: `cd MyFirstApp`
* Chạy ứng dụng: `npx expo start`


5. **Kết nối:** Quét mã QR hiện trên terminal bằng điện thoại để thấy ứng dụng chạy trực tiếp.
